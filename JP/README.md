## ハンズオンワークショップ: ローコードAI ― 誰でも使えるAI

[Go to English Page](https://github.com/mathworks/low-code-AI-workshop)

プログラミングの深い知識がなくても、自分の分野でAIを活用する方法を学びましょう。このハンズオンセッションでは、AIの基礎を簡単に振り返った後、MATLAB®の対話型ツールやアプリを使って人間の活動を分類する3つの演習を行います。

1. モバイルデバイスで取得したデータへのアクセスと前処理  
2. ライブ エディターの「データのクラスタリング」タスクを使ったラベルなしデータのクラスタリング  
3. 「分類学習器」アプリと「ディープネットワークデザイナー」アプリを使ったラベル付きデータの分類  

ワークショップ終了時には、プログラミングの高度な知識がなくても、さまざまな機械学習モデルや深層学習モデルを設計・学習できるようになります。また、対話型ワークフローからコードを自動生成する方法も学びます。これにより、モデルを再利用する際に手順をすべて手動で行う必要がなくなるだけでなく、プログラミングの習得やスキル向上にも役立ちます。
